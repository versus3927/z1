============================================================
CRM «Задача Z1» — готовая конфигурация 1С:Предприятие 8.3
(формат XML-выгрузки, версия формата 2.17, платформа 8.3.24+)
============================================================

КАК ЗАГРУЗИТЬ:
1. Создайте пустую информационную базу:
   «Добавить» → «Создание новой информационной базы»
   → «создание информационной базы без конфигурации».
2. Откройте базу в режиме «Конфигуратор».
3. Меню: Конфигурация → Загрузить конфигурацию из файлов…
   → выберите папку src из этого архива.
4. Дождитесь окончания загрузки, нажмите F7
   (обновить конфигурацию базы данных) и подтвердите.
5. F5 — запуск в режиме 1С:Предприятие.

ЧТО УЖЕ СДЕЛАНО:
- Разделы «Продажи», «Маркетинг», «Сервис»;
- Справочник «Клиенты»: источник появления, табличная часть
  «Контакты» (несколько телефонов и e-mail), многострочный
  комментарий, контроль заполнения при записи;
- Справочник «Контактные лица» (подчинён клиентам): роль,
  признак основного КЛ, телефон, e-mail, комментарий,
  контроль заполнения при записи;
- Классификаторы с предопределёнными элементами:
  виды взаимодействий (9), результаты (3), источники (6),
  роли контактных лиц (4) — видны в разделе «Сервис»;
- Документ «Взаимодействие» (разделы Продажи и Маркетинг):
  выбор контактного лица только среди контактов клиента,
  надпись «Взаимодействий не запланировано», кнопка
  «Запланировать взаимодействие» со связью документов,
  поля «Напомнить» + «Напомнить (дата и время)» —
  в заданный момент всплывёт напоминание с переходом
  в карточку;
- Отчёт «Взаимодействия по клиентам» (СКД): группировка
  по клиенту, даты, содержание, цветовая индикация:
  зелёный — будущая активность, жёлтый — последние 14 дней,
  серый — давние завершённые.

ОСТАЛОСЬ СДЕЛАТЬ ВРУЧНУЮ (5–10 минут):
1. В 1С:Предприятии включить напоминания:
   главное меню → Сервис → Настройки… → «Напоминания» →
   «Выводить напоминания автоматически».
2. Ввести тестовые данные: минимум 4 клиента, каждому —
   контактные лица; минимум 6 взаимодействий. Даты делайте
   разные: в далёком прошлом, на этой неделе и в будущем —
   тогда в отчёте загорятся все три цвета.
3. По желанию — дизайн: картинки подсистем, акценты.

Подробный разбор каждого решения — на сайте-гайде Z1.
